# Nodera

Nodera ile hazır bir Windows sanal bilgisayarı kiralayabilir veya uyumlu Windows bilgisayarınızda Hyper-V kullanarak kaynaklarınızı paylaşabilirsiniz. Kiraladığınız bilgisayarın masaüstüne Nodera içinden bağlanabilirsiniz.

## İndir

| Platform | Kullanıcı sürümü |
| --- | --- |
| Windows x64 | [Nodera 0.5.15 kurulum dosyası](https://github.com/c0denail/nodera/releases/tag/v0.5.15) |
| macOS | macOS kullanıcı sürümü ileride yayımlanacak. |

Windows kurulum dosyasını indirip çalıştırın. Bilgisayarınızı paylaşmak için Hyper-V desteği gerekir.

## 0.5.15

Uygulama Mağazası, ekranlı kurulum gerektiren uygulamaların sihirbazını kiraladığınız Windows masaüstünde açabilir. Kurulum adımlarını sanal bilgisayarın açık oturumunda tamamlayın.
